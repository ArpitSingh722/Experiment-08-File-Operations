# Experiment No. 8: File Reading, Line Counting, and Data Extraction

**Course Outcome:** CO-3  
**Student:** Vastav Nandedkar  
**Institution:** School of Computing, MIT Art, Design and Technology University, Pune  

## Aim
Create a Python script to read data from an input file, count the total number of lines, extract the first two lines, and write the extracted data into a new file.

## Problem Statement
Write a Python program that opens a text file (`input.txt`), reads all lines safely using UTF-8 encoding, computes the total line count, slices the first two lines, displays the results in the terminal, and writes the extracted lines to an output file (`extracted_output.txt`).

## How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/Experiment-08-File-Operations.git
   cd Experiment-08-File-Operations
   ```
2. Run the script:
   ```bash
   python file_processor.py
   ```
3. Inspect the terminal output or open `extracted_output.txt` to verify the extracted lines.
